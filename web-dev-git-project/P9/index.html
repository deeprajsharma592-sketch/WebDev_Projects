Responsive Flexbox Navbar & Equal-Height Card Grid

Flexbox Responsive Card Grid

Using display: flex, flex-wrap: wrap, and flex: 1 1 260px

Foundation

Main Axis & Cross Axis

Flexbox operates along two axes: the main axis (defined by flex-direction) and the perpendicular cross axis.

#flex-direction
Alignment

Justify Content vs Align Items

justify-content distributes spare space along the main axis, while align-items handles cross-axis positioning like stretch, center, or flex-start.

#alignment
Growth & Shrink

Flex-Grow, Shrink & Basis

The shorthand flex: 1 1 260px instructs cards to expand to fill leftover space, shrink when cramped below ideal width, and start at a baseline of 260px. Notice how this card has much more text, but its bottom button remains perfectly aligned with the other cards!

#flexibility
Responsive

Wrapping with Flex-Wrap

By default, flex items try to fit on a single line. Adding flex-wrap: wrap allows items to flow gracefully into subsequent rows on smaller viewports.

#responsive

Flexbox Key Properties Summary

Container Properties

  • display: flex
  • flex-direction: row | column
  • flex-wrap: wrap | nowrap
  • justify-content: space-between | center
  • align-items: stretch | center
  • gap: 20px

Item Properties

  • flex-grow: 1 (take free space)
  • flex-shrink: 1 (shrink if tight)
  • flex-basis: 260px (starting size)
  • flex: 1 1 260px (shorthand)
  • align-self: flex-end
  • order: 1
