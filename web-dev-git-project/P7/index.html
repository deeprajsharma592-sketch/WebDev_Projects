CSS Architecture

Design Tokens & Typography System

A centralized foundation built using CSS Custom Properties (Variables) for colors, modular type scale, spacing intervals, and component tokens.

1. Color Design Tokens

Defined in :root to enforce consistency across backgrounds, borders, and text.

--color-primary #1e90ff (Dodger Blue)
--color-secondary #ff6347 (Tomato Red)
--color-accent #3cb371 (Medium Sea Green)
--color-warning #ffa500 (Orange)
--color-surface #ffffff (Pure White)
--color-bg-page #f4f6f9 (Soft Canvas)

2. Modular Typography System

Proportional scale ensuring consistent visual hierarchy and readable line-heights.

H1 • --font-size-3xl (2.25rem / 36px)

The quick brown fox jumps over the lazy dog

H2 • --font-size-2xl (1.85rem / 29.6px)

The quick brown fox jumps over the lazy dog

H3 • --font-size-xl (1.5rem / 24px)

The quick brown fox jumps over the lazy dog

H4 • --font-size-lg (1.25rem / 20px)

The quick brown fox jumps over the lazy dog

Lead Paragraph • --font-size-md (1.125rem / 18px)

Leading paragraphs introduce sections with higher emphasis and comfortable line height.

Body Text • --font-size-base (1rem / 16px)

Standard body text optimized for long-form reading comprehension across all device form-factors.

Small / Caption • --font-size-sm (0.875rem / 14px)

Metadata, captions, legal disclaimers, and auxiliary footnotes.

Code / Monospace • --font-family-mono

Inline sample: const greeting = "Hello, CSS Tokens!"; or keyboard key: Ctrl + C

Blockquote
"Design tokens are the visual atoms of the design system — specifically, they are named entities that store visual design attributes."
