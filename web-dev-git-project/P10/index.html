Advanced Flexbox Header & Footer Demonstration

Inspect this page to see how advanced Flexbox rules—such as flex-grow: 1, flex-shrink, align-self, and order—are orchestrated to build production-ready application navigation and footers.

Header Flex Structure

The search bar in the header expands automatically using flex-grow: 1, absorbing available whitespace while respecting max-width: 420px.

Order Manipulation

Resize your viewport to under 768px. Watch how CSS order dynamically shifts the search input to the bottom line of the header without modifying HTML structure.

Multi-Column Footer

The footer distributes asymmetric columns with flex-basis and flex-grow, allowing the newsletter and brand columns to take 2 shares while navigation takes 1 share.
