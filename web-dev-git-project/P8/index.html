CSS Positioning Explained

CSS positioning allows you to take elements out of the normal document flow and place them precisely where needed. In this project, we demonstrate:

  • position: sticky: The navbar above behaves normally until you scroll, then stays pinned at top: 0.
  • position: relative: Serves as the positioning boundary/coordinate parent for absolute children.
  • position: absolute: Positions badges and hover overlay layers precisely within relative cards.
  • position: fixed: The circular button in the bottom-right corner stays anchored to the viewport.

Positioning Rules Quick Reference

Property Value Document Flow Reference Point Common Use Case
static Normal flow Default browser placement Standard document elements
relative In normal flow Self (original position) Anchor for absolute children
absolute Removed from flow Nearest positioned ancestor Card badges, modal overlays, tooltips
fixed Removed from flow Browser viewport Back to top button, sticky chat head
sticky In flow until scroll threshold Scroll parent / viewport Sticky navigation bars, table headers
